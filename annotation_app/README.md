# Kraken Annotator

Независимое локальное приложение для быстрой разметки строк рукописного
текста и экспорта в Kraken 7 BLLA segmentation training.

Запуск:

```powershell
.\annotate.bat
```

Остановка и статус:

```powershell
.\annotate.bat stop
.\annotate.bat status
```

Приложение открывается на `http://127.0.0.1:8020`. Собственная SQLite-БД,
загруженные файлы и экспорты находятся в `annotation_app/data/`.

## Быстрый поток

1. Нажать `Импортировать raw_dataset` или выбрать папку.
2. Протянуть прямоугольник вокруг одной строки.
3. Нажать `Enter`; если начать следующую рамку, предыдущая принимается
   автоматически.
4. Двойной клик сохраняет изменения и открывает следующее изображение.
5. Выбранную baseline можно поправить слайдером справа.

Горячие клавиши:

- `Enter` — принять текущую рамку;
- `Delete` — удалить выбранную строку;
- `Ctrl+Z` — отменить;
- `N`/`→`, `P`/`←` — следующее/предыдущее изображение;
- колесо — масштаб, `Space` + перетаскивание — панорамирование;
- `0` — вписать изображение;
- `1`/`2` — разметка/датасет.

## Формат экспорта

Экспорт содержит оригинальные изображения, PAGE XML 2019-07-15 с polygon
boundary и baseline каждой строки, `train.lst`, `validation.lst`, `test.lst`,
`metadata.json` и `experiment.yml`. Manifest-файлы содержат пути к PAGE XML,
как ожидает установленный загрузчик Kraken 7.

Официальная документация Kraken указывает, что для segmentation training
обязательны baseline-полилинии, а region polygons необязательны. Экспорт
намеренно задаёт `region_class_mapping: []`, чтобы обучать детектор строк, а не
классификатор областей страницы.
