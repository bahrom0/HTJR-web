# Tajik HTR Studio — Frontend

Modern web interface for handwritten and historical Tajik text recognition.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env.local`:
   ```env
   VITE_API_URL=http://localhost:8000
   ```
3. Run dev server:
   ```bash
   npm run dev
   ```
